# Game music

Background music for the games. Drop tracks in here.

- **Format:** `.mp3` plays everywhere (iPad included). `.m4a` also works.
- **Names:** short and lower-case, e.g. `calm-piano.mp3`, `circus-march.mp3`.
- **Loops:** tracks that loop cleanly sound best, since they'll repeat.
- **Size:** aim for under ~3 MB each, since the public site downloads them.
